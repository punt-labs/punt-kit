Punt Labs · the toolchain, as a language

Nine tools. Two layers.
One grammar.

Every Punt Labs tool is a small language: a set of nouns it manages and a set of verbs you — or your agent — speak to it. The layers come from how we build: Grounding decides what to build and how to specify it; Building Blocks make agents more capable while you build it. Each tool ships the same vocabulary through four doors — library, CLI, MCP server, and slash commands — from a single codebase.

The shared grammar

one vocabulary, every tool

Verbs that mean the same thing everywhere. A tool may have a small language of its own, but these words are never redefined.

enable · disable
Turn a tool on or off for a repo — one committed marker, written the same way from every surface. Never a boolean, never automatic, never a side effect.
help
Every tool explains itself: one quick-reference command per plugin.
doctor
Every tool with an environment can check it and say what's wrong.
poll
Every tool with an inbox checks it the same way: poll 5m to watch, poll to check now.
remember · ingest · learn
The capture triad: remember a specific durable fact, ingest a URL, learn a distilled lesson that shapes future retrieval.
noun.verb
Large agent-facing surfaces speak in dotted pairs — scene.show, topic.publish — so the noun set stays visible in the verb.
four doors
Library · CLI · MCP server · slash command — one vocabulary through every door, from a single codebase. The door changes; the word doesn't.

Grounding decides what to build. Building Blocks help build it. The grammar keeps nine small languages from becoming nine dialects.
