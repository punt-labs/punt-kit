## Mandatory core and workflow changes

**Package deterministic operations as a real CLI.** Extend `prfaq-350` with init/template discovery, lint, compile, export, doctor and version/capabilities. Use one supported package format and install resource assets with it; adapters resolve assets from installed package paths, not `CLAUDE_PLUGIN_ROOT` or a source checkout. Keep the linter implementation/config single-sourced. Provide JSON success, policy failure, missing dependency, compiler failure and cancellation results with artifact/log paths and nonzero failure exits. Bound process lifetime, terminate child process groups, isolate concurrent build directories and publish completed artifacts atomically. Doctor should identify LaTeX, Biber, Pandoc and optional media/source capabilities accurately. Do not require an MCP server merely to equalize the toolkit's surface count.

**Give meetings durable structured state and a deterministic reducer.** Record meeting/document identity and input hash, stage, agenda, role/child IDs, independent evidence, round, votes, decision rule, escalation and user resolution, artifact references and resumable phase. Validate role outputs before synthesis. The reducer enforces the existing one-way/two-way door rules and preserves human decisions; it does not generate reviewers' opinions. New round agents receive the specified previous-round evidence, whereas round-one agents cannot see each other's positions prematurely. Timeouts/missing roles produce incomplete evidence, never invented unanimity. Cancellation stops outstanding reviewers and persists the completed portion. Document edits invalidate or explicitly rebase affected evidence.

Replace brittle markdown-as-database interpretation with a versioned meeting record and rendered Markdown summaries. [`meeting-hive.md:124`](https://github.com/punt-labs/prfaq/blob/833cea76161cc32ab8a8dcffba984b0b2bfc5c6a/plugin/commands/meeting-hive.md#L124) currently depends on particular table wording for later listen/feedback workflows. Keep readable summaries and a backward-compatible importer for prior artifacts; migration must handle collisions and preserve originals until a verified destination exists. Feedback revisions need stable directive IDs, change provenance and checkpointing so resume does not reapply edits. Research/review/meeting skills remain authored agent workflows; their deterministic state transitions and file operations belong in the CLI services.

**Make evidence and optional integrations explicit.** [`plugin/agents/researcher.md`](https://github.com/punt-labs/prfaq/blob/833cea76161cc32ab8a8dcffba984b0b2bfc5c6a/plugin/agents/researcher.md) and [`peer-reviewer.md`](https://github.com/punt-labs/prfaq/blob/833cea76161cc32ab8a8dcffba984b0b2bfc5c6a/plugin/agents/peer-reviewer.md) describe internal sources that their grants may not expose. Onboarding must report available authorized sources, missing capabilities and citation provenance; no silent skip masquerading as complete research. Adapter capabilities bind native connectors/search or Quarry to the workflow. User-controlled source configuration is separate from persona prompts, and source documents do not authorize actions. Automatic research ingestion must name the target collection and require the configured scope; it must not switch global Quarry state.

[`meeting-listen.md:13`](https://github.com/punt-labs/prfaq/blob/833cea76161cc32ab8a8dcffba984b0b2bfc5c6a/plugin/commands/meeting-listen.md#L13) checks an exact Claude Vox MCP tool name and falls back to text. Replace that dependency with the current Vox semantic capability contract, retaining visible text fallback. Session voice overrides, capture/playback request IDs, cancellation and speaker assignment belong to Vox's native adapter with PRFAQ supplying content/role intent. Lux should consume the same structured meeting state, not interpret model-authored layouts as authoritative votes.

The installed plugin files inspected contain no prose-lint hook registration despite meeting prose referring to one. Add an explicit distributed lint/finalization path and honest documentation. Hook assistance can offer immediate feedback, but persisted reports/artifacts should receive deterministic validation regardless of which native editor tool produced them. Live debate prose needs an explicit validation step if it is advertised as linted.

## Native integrations and deferred Codex research

**Codex (deferred).** Deliver a native plugin of skills, commands through supported skill invocation, reference assets and finite CLI access. Port each authored workflow deliberately: research and review use real native subagents; meetings spawn separate role agents, collect evidence, run the reducer and ask for decisions through the available stock interaction surface. Agent TOML registration must use supported discovery/ownership. An ordinary Codex session cannot assume a Plan-only question tool is callable; supply a valid conversational/native interaction path and suspend the meeting until an actual answer. Use the stock delegation lifecycle for cancellation/child completion; do not embed an app-server host as the definition of plugin support. Any automatic edit lint hooks must use Codex events and documented payloads. Authoritative meeting/session context needs the shared Codex propagation spike when operations are stateful.

**OpenCode.** Provide native commands and role agents plus a TypeScript plugin with finite typed tools over the packaged CLI. The coordinator uses supported child-session/delegation APIs with explicit tools, models and permission policy. It derives session identity from tool context, never static MCP env. Avoid awaiting a prompt to the same session from its own awaited tool hook. A native TUI dialog/status surface presents agenda selection, decisions and resume state; headless mode uses explicit supplied decisions or pauses, never chooses on behalf of an absent user. Optional Vox/Lux integrations remain separately discoverable. Server and TUI components share record IDs, not mutable global current-meeting variables.

**pi coding agent.** Publish a native extension/package containing typed CLI tools, commands, authored skills and native UI selection/input. Pi has no built-in subagent API. A declared delegation component is therefore a requirement for independent PRFAQ reviews: the shared Punt pi supervisor launches separate supported pi SDK sessions/processes, supplies role prompts and evidence snapshots, limits tools, drains JSON events, enforces timeout/cancellation and returns validated results. Independent reviewer contexts are mandatory even when the same model is chosen. Avoid a generic MCP bridge and direct imports of private Python APIs. Tree navigation, forks, restarts and `agent_settled` semantics must map to durable meeting checkpoints; repeated callbacks cannot repeat final decisions.

All integrations expose the same document defaults, stage vocabulary, reviewer roles, meeting semantics and generated artifacts through native UX. Capability gaps block the affected mode with a concrete explanation. Preserve the existing Claude implementation against the same shared meeting/CLI contracts. Install/register/enable are separate, and no installer should grant broad global permissions or enable every detected harness.

For each native harness, create from a packaged template, research with an unavailable optional connector, review with two independent critics, run an interactive meeting, run a hive meeting with a second-round escalation, apply feedback once, lint, compile and export. Record actual child sessions/results, not a model's assertion that four roles ran. Repeat with two concurrent meetings on different documents and conflicting edits to one document; reopen, fork, compact and cancel in each phase. Deny a native tool permission; disable/remove integration midway; start without Vox/Lux/Quarry; retain readable resumable records and no orphaned reviewer or compiler process. Run voice/listen and display cases when peers are installed, and explicit text cases when absent. Reuse lint/permission tests, add reducer/process-contract tests, then perform real stock TUI interaction checks; headless prompt evaluations do not certify questions, independent orchestration or audio behavior.
